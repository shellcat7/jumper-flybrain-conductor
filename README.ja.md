# Fly-Wired Crab

**ショウジョウバエの神経索の配線をもつネットワークが、カニ型ロボットの歩き方を切り替える（シミュレーション）**

[English README](README.md)

KingKong Robotics のオープンソース六脚カニ型ロボット **Jumper** を MuJoCo でシミュレーションし、
ショウジョウバエの腹側神経索（VNC）の配線を使ったリカレントネットワークで制御しました。
配線は **MaleCNS v1.0** の 24,154 ニューロン分で、シナプスには神経伝達物質から推定した符号をつけています。

このネットワークは関節を直接は動かしません。12 個の凍結済み運動プログラムのうち、どれに歩かせるかを
毎ステップ決める指揮役（オーケストレーション）です。脚が1本動かなくなる、床が滑る、といった異常を
ネットワークは教えられません。自分の脚の感覚から気づいて、合った歩き方に切り替えます。
弾が飛んでくると、ハエの巨大線維経路をまねて手で設計した逃避反射が、横に避ける・かがむ・跳ぶ・爪で受ける、のどれかを行います。

このシミュレーションの記録 1 本から、Crab Robot Challenge 2026 第1ラウンド用に 38 秒の短編を作りました。

## シミュレーションのもの、そうでないもの

| | |
|---|---|
| **ロボットの動き** | MuJoCo（GPU 上の mujoco-warp）の物理計算を 200 Hz で記録し、Blender でボディごとに再生しています。ロボットの動きに手付けはありません。 |
| **センシング** | 逃避反射は弾の位置をシミュレーターから直接読んでいます（全方位、ノイズ・遅れなし）。実機の Jumper は前向きの RGB カメラと dToF だけなので、外部のトラッキングかセンサーの追加が必要です。遅れがあれば 0.3〜0.45 秒の猶予から削られます。 |
| **「弾」** | 1.8〜3 m 先から 0.45 秒で届く直径 25 mm の球（秒速 4〜7 m）を、レーザー弾として描いています。 |
| **手付け・後から置いたもの** | ドローン（弾の発射位置にいて、その間を飛ぶよう手付け）、シャッター、シャッターに激突するドローン。最後の蛇行は走る向きの指令で、ロボットが選んだものではありません。ゴミ箱と大型の鉄製ゴミ箱は、蛇行して曲がった場所に後から置いた美術で、シミュレーションにはありません。 |
| **「ハエの脳」** | 脳の再現ではありません。ハエの神経索の配線を土台に使ったネットワークです。配線をシャッフルした対照でも同じ成績（+48.1%、本物の配線は +47.7%）なので、成績の向上は「運動プログラムを選ぶ」という設計から来ていて、ハエの配線そのものの効果ではありません。 |
| **再生速度** | 一部をスロー（最大 x0.125）や早回し（x2）にしています。左下の HUD に常に倍率を表示しています。 |

## 結果（シミュレーション、条件ごとに 64 台）

| | 公式ポリシー | 指揮役 + 反射（dgate6-s1、299 回目） |
|---|---|---|
| 平地の速度比（歩く・走る・曲がるの平均） | 0.951 | 0.951 |
| 24 の異常条件、異常発生後の平均速度比 | 0.485 | **0.717（+47.7%）**、19 改善・0 悪化 |
| 同じ手順の 2 本目のシード | | 0.717（+47.6%）、20 改善・0 悪化 |
| **対照：同じネットワークで配線をシャッフル** | | 0.719（+48.1%）、19 改善・0 悪化 |
| 平地の最高速度 | 1.42 m/s | 1.59 m/s |
| 投げたボールが当たった割合（1 m 先から、飛行時間 0.3 / 0.4 / 0.6 / 0.9 秒） | 1.00 / 1.00 / 1.00 / 1.00 | 0.49 / 0.00 / 0.00 / 0.00 |

異常：脚 1〜2 本のトルクをゼロにする（LF、RF、LM、RR、LM+LR、LM+RR。ポリシーはその脚にも指令を出し続ける）、
足の摩擦を 0.03 / 0.06 に下げる。歩行（0.3 m/s）、走行（0.6 m/s）、旋回（0.5 m/s、1.5 rad/s）中の 2 秒目に発生。
速度比 = 異常発生後の平均前進速度 ÷ 指令速度。全セルは [results/scoreboard-dgate6-299-gfmja.md](results/scoreboard-dgate6-299-gfmja.md)。

まだ弱いところ：同じ側の 2 本が死ぬ場合（LM+LR、0.04〜0.32、公式と変わらない）と、いちばん速い球（飛行 0.3 秒、半分は当たる）。
